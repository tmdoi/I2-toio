# 1. Python最初の一歩

ロボットを動かす前に，Pythonがどんなものかを少しだけ体験します．ここでは**Thonnyの画面の下半分にある「Shell（シェル）」**を使います．Shellは，入力するとすぐ答えが返ってくる場所です．

Shellの `>>>` のうしろに入力して，**Enterキー**を押してください．

---

## 電卓として使ってみる

```python
1 + 2
```

Enterを押すと `3` と表示されます．

```python
100 * 8
```

かけ算は `*`，わり算は `/` を使います．

---

## print：画面に表示する

`print`（プリント）は「表示して」という命令です．

```python
print("こんにちは")
```

文字は必ず `"` （ダブルクォート）ではさみます．はさみ忘れるとエラーになります．

```python
print("toioを動かすぞ")
```

---

## 変数：値に名前をつけて置いておく

`=` を使うと，値に名前をつけて覚えさせることができます．この名前を**変数**といいます．

```python
speed = 30
```

これで `speed` という名前の箱に `30` が入りました．中身を見てみましょう．

```python
print(speed)
```

計算にも使えます．

```python
print(speed * 2)
```

中身はあとから書きかえられます．

```python
speed = 50
print(speed)
```

あとで出てくるプログラムでは，この `speed` のような変数の数字を書きかえて，ロボットの動きを調整します．

---

## for：くり返す

同じことを何回もやりたいときは `for`（フォー）を使います．Shellでは1行では書けないので，Thonnyの**上半分（エディタ）**に次の2行を書いて，緑の**Run（実行）**ボタンを押してください．保存を聞かれたら，好きな名前（例：`test1.py`）で保存します．

```python
for i in range(5):
    print("がんばるぞ")
```

`がんばるぞ` が5回表示されます．

### ここが大事：字下げ（インデント）

2行目のはじまりが右にずれているのがわかりますか．これを**字下げ（インデント）**といいます．Pythonでは「ここは `for` のなかみですよ」という意味を，この字下げで表します．

- 字下げは**スペース4個**（Thonnyでは `Tab` キー1回でOK）
- 字下げを忘れるとエラーになります

`range(5)` の数字を変えると，くり返す回数が変わります．

---

## やってみよう

**やってみよう1**: `print()` を使って，自分の名前を画面に表示してみましょう．

**やってみよう2**: 次のプログラムをエディタに書いて実行し，何が表示されるか確かめましょう．`range()` の数字も変えてみましょう．

```python
for i in range(3):
    print(i)
```

<details markdown="1">
<summary>答えを見る</summary>

`0` `1` `2` と表示されます．Pythonは **0から数え始める**のがふつうです．

</details>
